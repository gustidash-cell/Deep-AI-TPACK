## 🌟 Fitur Utama Platform Digital

1. **Dashboard Utama (`index.html`)**
   - Ringkasan metrik penelitian DDR Siklus 1.
   - Fitur Unggulan **Laboratorium Prompt & Simulator AI-TPACK Interaktif** (Uji prompt Socratik, Pemeriksa Error, dan Generator Soal Kontekstual Indonesia secara live di browser).
   - Kerangka Metodologis Pedagogy-First AI Integration.

2. **Modul HLT Siklus 1 (`HLT_Siklus1_Interactive.html`)**
   - Lintasan Belajar Hipotesis (Hypothetical Learning Trajectory) 3 Pertemuan.
   - Accordion interaktif untuk alur aktivitas, prediksi respons, dan kartu *Antisipasi Didaktis Pedagogis (ADP)*.
   - Rubrik kevalidan instrumen oleh pakar.

3. **Modul ALT & Komparator Lapangan (`ALT_Siklus1_Interactive.html`)**
   - Matriks observasi lapangan 99 Indikator Observasi Siklus 1.
   - Filter status pencarian instan (`✓ Sesuai`, `≈ Sebagian`, `✗ Berbeda`, `⭐ Unexpected Finding`).
   - Implikasi operasional & revisi desain untuk HLT Siklus 2.

4. **Lembar Kerja Mahasiswa P1 (`LKM_P1_Interactive.html`)**
   - Audit Penjelasan AI vs Buku Teks.
   - Protokol Observasi Video Pembelajaran.
   - **Game/Alat Klasifikasi Interaktif 8 Kartu Tugas SPLDV** (Kategori A, B, C) dengan umpan balik otomatis.

5. **Lembar Kerja Mahasiswa P2 (`LKM_P2_Interactive.html`)**
   - Template Rancangan Aktivitas 9 Komponen untuk 4 Kelompok Tematik.
   - Laboratorium Prompt & Perpustakaan 4 Prompt Wajib.
   - Formulir Tinjauan Sejawat (*Peer Review*) & Log Revisi 5 menit.

6. **Instrumen Angket Pre-Test & Post-Test AI-TPACK (`Angket_Pre_Post_Test.html` & `index.html#angket-evaluasi`)**
   - Live embed responsif Google Forms untuk Pre-Test (sebelum P1) dan Post-Test (setelah P3).
   - Fitur salin tautan instan, ekspansi tinggi form (*comfortable/expanded view*), dan muat ulang dinamis.
   - Matriks indikator 7 dimensi AI-TPACK (AI-TK, AI-TCK, AI-TPK, ADP, Etika AI).

## 🎨 UI/UX Pro Max & OpenDesign System Standards
- **Design System Toksik-Bebas (Anti-AI-Slop)**: Menggunakan Academic Cobalt Palette (`--primary: #1d4ed8`), bukan Tailwind Indigo klise.
- **Bento Grid Architecture**: Kartu berbingkai perimeter halus, tanpa garis aksen kiri tebal.
- **Monoline Inline SVG Icons**: Ikon konsisten berstandar monoline stroke 1.8px tanpa emoji pada antarmuka fitur.
- **Aksesibilitas & Standar WCAG AAA**: Kontras teks tinggi, navigasi keyboard `:focus-visible`, dan dukungan `prefers-reduced-motion`.
- **Default Light Mode** dengan tombol alih cepat **Mode Terang / Mode Gelap**.
- **Fitur Dwi-Bahasa (Bilingual)**: Bahasa Indonesia (Default) & English (US).

## 🚀 Cara Menjalankan (Local & GitHub Pages)

### 1. Jalankan Lokal
Cukup buka berkas `index.html` langsung di peramban (Chrome / Edge / Firefox) atau gunakan ekstensi Live Server.

### 2. Aktifkan GitHub Pages
1. Buka repositori di GitHub: `https://github.com/gustidash-cell/Deep-AI-TPACK`
2. Masuk ke menu **Settings** > **Pages**.
3. Pada bagian **Branch**, pilih `main` / `root` lalu klik **Save**.
4. Website akan aktif secara publik di `https://gustidash-cell.github.io/Deep-AI-TPACK/`.
